A - TCP
Largura de Banda (Quantidade de informação que pode ser passada de uma única vez)
- Orientado a conexão )tem transmissor e receptor, tem um modelo que permite comunicação entre os dispositivos, sabe-se do modelo que ele será organizado) (Ele vai comentando como está indo a transferência de arquivos)
- ponto-a-ponto (Essa conexão permite que a informação )
- confiabilidade (Ele aguarda a confirmação, em caso de demora do respondimento ele é entregue novamente)
- full-duplex (Permite a entrega e recebimento de dados simultaneamente)
- entrega ordenada (Para que quando os pacotes forem entregues o recepto poder montar a  que anteriormente foi dividida)
- controle de fluxo (Permite que o receptor comunique ao transmissor que a linha está ocupada entregando algum arquivo, )

Soma de verificação, para que o receptor possa conferir que n° de confirmação bate com a soma, em caso de sucesso o transmissor não precisa mandar de novo, caso contrario ele manda de novo

Tanto o TCP quanto UDP usam o protocolo IP para a entrega dos pacotes. Após o encapsulamento, os roteadores usam basicamente os campos do IP

3 Protocolos da Camada de internet
A protocolo IP
Permite a transferencia de dados, no formato de datagramas, entre os nós da rede.
O endereçamento IP permite identificar um dispositivo pertencente a uma rede de computadores
2 versões
- IPv4: Endereços formados por 32 bits separados por ponto final
- Os endereços estão divididos em 5 classes: A,B,C,D,E
- IPv6: endereço formados por 128 bts. São divididos em 2 blocos: 64 bits inicias (rede) e 64 bits finais (hosts)

Protocolo ICMP
tem a funções de indentificar erros em uma rede de computadores.Exemplos de comandos: PING E TRACEROUTE
Muitos firewalls, servidores e mecanismos de proteção de rede bloqueiam respostas a requisição ICMP, com forma de proteger estes equipamentos e a rede como um todo de tentativas e a rede como um todo de tentativas de mapeamentos e posteriormente atques.
